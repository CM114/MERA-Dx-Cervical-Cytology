# Data and code availability

## Code Availability

The public repository contains the paper-related training, evaluation, audit, configuration, plotting, and release-validation code, together with compact source data for the reported tables and selected figures.

## Data Availability

Raw XUData and CRIC medical images are not included in this repository. The public release includes only a synthetic manifest, a data dictionary, and aggregate result files that do not contain image paths or subject identifiers. Users must obtain the underlying datasets from their original providers and follow the providers' licensing, access, privacy, and ethics requirements.

Model weights and complete image-level prediction pools are also not included. The aggregate files are intended for result checking and plotting, not for reconstructing the original images.

## Reuse boundary

Public GitHub visibility must not be interpreted as permission to redistribute the underlying medical data. No claim is made here about patient-level or slide-level independence, external validation, or clinical deployment.
